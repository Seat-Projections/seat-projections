Architecture

Core modelling foundations

01 · Count

Exact IRV count engine

Every seat is decided by a full instant-runoff count reproducing the Electoral Act 2002 procedure, including statutory lookback tie-breaks — not a uniform-swing approximation.

Verified vote-for-vote against all 88 VEC 2022 distributions and the 48 published 2018 counts
02 · Geography

Booth-to-district mapping

Federal polling places are assigned to state districts geometrically: a booth counts only if it sits inside the district and within 1 km of its own federal division.

EBC 2021 redivision boundaries · AEC polling-place locations
03 · Preferences

Fitted preference flows

How each party’s ballots split between remaining candidates is fitted from published distributions of preferences — for benchmarks, leaving out the scored district so nothing is fitted on its own result.

VEC, AEC and other state commissions’ published distributions
04 · Uncertainty

Monte Carlo seat simulation

Each simulation redraws statewide swing, regional deviations, per-seat noise and preference flows, then counts all 88 districts — turning point estimates into probabilities and seat ranges.

Up to 5,000 runs per forecast
The models

Two different questions

Model 1 — “nothing changes” baseline

Every polling place’s votes from the most recent federal election are put into the state district it sits in, and each district’s preferential count is replayed assuming nothing changes: same parties, same first preferences, same preferences. A Bradley–Terry strength is fitted for each (from-party, to-party) split so transfers exist for any set of continuing parties. Monte Carlo noise turns the replay into seat probabilities.

It uses no polling and no candidate information — a deliberately primitive floor the real model must beat. It does well when the federal and state elections are close together and badly when something big has changed.

Model 2 — core-candidate heuristic

A preferential count only has a few decisions that change the winner. Model 2 splits each seat’s declared 2026 candidates into core (top four of the pre-preference totals in at least 5% of runs) and minor, sends minor votes straight to the core along per-party flow vectors, then resolves the core contest explicitly for whichever exclusion order occurs — tracking where each pile of votes originally came from.

Primaries are the 2022 district results swung to the 2026 polling average; One Nation’s geographic pattern comes from its 2025 federal booth pattern.

Model 2 specification

primary[seat, party] = baseline_2022[seat, party] + statewide_swing[party] (one draw per run, shared by all seats) + regional_deviation[region, party] + seat_noise[seat, party] (re-normalised to sum to 100% per seat) core total T[k] = primary[k] + Σ_m primary[m] · f[m → k] core stage: exclude the lowest core candidate; their pile splits between the continuing candidates by each vote’s party of origin (origin tracking); repeat until two remain — the higher wins.

Statewide swing is centred on the polling average with spread from historical polling error; regional deviation captures uneven swings; seat noise covers candidate effects and retirements. All noise widths are placeholder values — see the caveat on the projections page.

Polling

How the polling average is built

Model 2 uses a deliberately simple average: each pollster’s latest eligible poll within 35 days of the newest poll in the register, equally weighted. There is no house-effect adjustment, no exponential decay and no sample-size weighting. The register is maintained from electiontracker.au.

Independence charter

Non-partisanship & citation

Seat Projections is an independent civic data project. It accepts no donations, has no party affiliation and no advertising; every number on this site is produced by open code from published electoral data, so any result can be recomputed and challenged.

Corrections and methodology questions are welcome via the repository’s issue tracker.
