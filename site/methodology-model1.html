Methodology · 02

Model 1 — “nothing changes”

A deliberately primitive baseline: replay the most recent federal election’s polling-place votes inside each state district, assuming nothing changes. It exists so the real model has a floor to beat.

Every polling place’s votes from the most recent federal election are put into the state district it sits in, and each district’s preferential count is replayed assuming nothing changes: same parties, same first preferences, same preferences. A Bradley–Terry strength is fitted for each (from-party, to-party) split so transfers exist for any set of continuing parties. Monte Carlo noise turns the replay into seat probabilities.

It uses no polling and no candidate information — a deliberately primitive floor the real model must beat. It does well when the federal and state elections are close together and badly when something big has changed.

Step 1

District votes

Federal polling places are assigned to state districts by location — inside the district and within 1 km of their own federal division — and summed into district first preferences by party group. Declaration votes (absent, postal, provisional) have no location and are left out.

Step 2

Preferences

The AEC publishes, for every booth, how each party’s ballots split between that division’s final two. A Bradley–Terry strength is fitted for each (from-party, to-party) pair, giving a transfer for any set of continuing parties — including combinations never seen federally.

Step 3

Count & noise

Each district is counted to the final two. Each Monte Carlo run multiplies every party’s vote by a shared statewide factor and a district factor, and every party’s attractiveness as a preference recipient by a statewide factor — turning the single replay into seat probabilities.

Independents are pooled as one IND* group, so a federal independent’s vote stays in the district as an “independent” even if no independent stands at state level — the “nothing changes” assumption taken literally, and the model’s biggest weakness.
