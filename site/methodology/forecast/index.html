Methodology · 03

Forecast Model

The model behind the 2026 projections combines past state results, current polls and the candidates standing in each district. It simulates thousands of elections to estimate each candidate’s chance of winning.

Called model2 in the code and archived runs.

Polls estimate support across Victoria, but seats are decided locally. The model uses past results to estimate where each party’s support is strongest. It then adjusts those votes to the polls and estimates how preferences could decide each contest.

Two baseline options

The Forecast Model has two options for where its baseline comes from. The state baseline is the default. It uses the previous state election’s results and preference counts in each district. The federal baseline uses the preceding federal election’s polling-place votes mapped into state districts and the AEC’s round-by-round preference counts. Declaration votes and votes from booths the mapping cannot place are allocated within each federal division so each district keeps its own party pattern, with statewide totals matched exactly to the official AEC figures.

Everything else is identical: the candidate list, polling average, regional and district shifts, and the count engine. A few differences remain because of the data itself. Polling places are assigned to districts by location, so the federal baseline is a map of booth votes rather than official district results. Parties with little federal presence, such as the WA Nationals, start low. Federal preference flows come from federal how-to-vote patterns across fewer divisions. New South Wales is the one structural exception: its state elections are optional preferential while federal elections are compulsory preferential, so the federal option takes its party preference shares from the federal count but its exhaustion rates from the previous NSW state count. Finally, the federal baseline has party votes only. Independents use the state election’s information in both versions, and the pooled federal independent vote drops out like any party that is not standing.

The state baseline is the default because it scored better on the backtests below: 329 of 380 seats right across the five elections, against 318 of 380 for the federal option. We also tested widening the federal district differences and it did not improve the backtests. The state baseline is the published forecast on the projections page. The federal baseline is kept for comparison and is linked from the benchmark table below.

How the forecast works

  1. Start with local votes. The baseline election provides the starting first-preference shares in each district: the 2022 state election by default, or the 2025 federal election’s votes inside each district for the federal option. The model uses the declared 2026 candidate list. One Nation and selected independents use the separate estimates described below.
  2. Adjust to the polls. Each simulation draws a statewide vote target around the polling average. Each party group’s district votes are scaled proportionally towards that target.
  3. Allow for local differences. The model adds a shared shift for each region and a separate shift for each district. Victoria uses its eight Legislative Council regions. The Queensland, South Australian and Western Australian backtests use grouped ABS SA4 statistical areas. Vote shares are adjusted to total 100% in each seat.
  4. Identify the main contenders. A preliminary set of simulations identifies candidates who finish in the top four on first preferences at least 5% of the time. These candidates, plus selected credible independents, form the core group. Votes for other candidates transfer directly to this group using estimated preference flows.
  5. Count the remaining contest. The lowest candidate is eliminated and their votes transfer to the remaining candidates. The model tracks which party each vote originally supported. This repeats until two candidates remain, and the one with more votes wins.
  6. Repeat and report the results. Each simulation varies votes and preference flows. A candidate’s win chance is the share of simulations they win. Party seat estimates are averages across those simulations.

The sizes of the random shifts are provisional settings, not fully calibrated estimates of election uncertainty. Backtests show that the model’s ranges are too narrow. Read the limitations on the projections page before quoting the forecast.

Keeping track of preferences

A candidate can receive votes from several other parties before being eliminated. The model keeps these votes separate by their original party. For example, votes that started with the Greens still follow the estimated Greens preference pattern, even after passing through another candidate.

These transfers are estimates from past counts. They do not reconstruct each voter’s ballot.

One Nation & independents

One Nation received only 8,077 lower house votes in 2022. Its local support is therefore estimated from 2025 federal polling places, then scaled to current state polling. Selected independents with a strong previous result or public profile receive a separate local vote estimate with greater uncertainty.

Polling

How the polling average is built

Each pollster contributes its latest eligible poll, provided it falls within 35 days of the newest poll in the register. Each poll gets equal weight, regardless of sample size. The average does not adjust for a pollster’s past tendency to favour a party or give extra weight to newer polls within that window. The register draws on electiontracker.au.

Forecast history

Forecast history

The forecast history starts on 1 September 2026, with a snapshot scheduled every two weeks. Dates are skipped when the polling average has not changed. Each snapshot includes only polls whose fieldwork ended at least two days earlier. This cutoff approximates when a poll would have been published.

The backfilled snapshots up to 10 November 2026 are retrospective: they were generated on 16 November 2026 with the final candidate fields and current model settings, so they show what the model would have said, not forecasts published on those dates. Snapshots made from now on are frozen when generated.

Drag the timeline under the map on the projections page to explore earlier forecasts. Each mark is a saved model run. Map colours change smoothly between marks, while the figures show the latest saved run at or before the selected date. You can also open the 13 October snapshot directly.

To reproduce the history, run run_model2.py --snapshots. Use --as-of YYYY-MM-DD for a particular date.
