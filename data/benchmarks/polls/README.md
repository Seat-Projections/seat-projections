# Final pre-election state polls (backtests)

`final_polls.csv`: for each scored state election, every pollster's **latest** statewide lower-house
primary-vote poll that ended within 35 days of the newest poll before polling day (the same rule model2
uses for 2026), generated by `scripts/fetch_final_polls.py` from the pinned Wikipedia revisions in `source`
(retrieved 16 Nov 2026; raw wikitext cached, gitignored, under `raw/`). Only the latest election
per state is included.

- `lnp` = the Coalition (Liberal + Nationals, or LNP in Queensland).
- `onp` is blank where the poll did not report One Nation separately; One Nation is then inside `oth`.
- `oth` = everything else (independents, other parties, and any category the pollster merged, e.g. KAP
  in Queensland 2024, Best in SA 2022). Rows can sum to 99-101 because of pollster rounding.
- Dates are the end of fieldwork where Wikipedia gives a range, otherwise the single date listed
  (sometimes the publication date).
- Excluded: Queensland 2024 "The Courier-Mail" reader survey (no named polling firm).
