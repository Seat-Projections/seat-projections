# Benchmarking

Every model writes a standard `seat_probabilities.csv` (see
[`../modelling/README.md`](../modelling/README.md#standard-outputs)): for each district, a probability
for each candidate (or party group) to win. These three metrics score that file against the declared
result.

## Metrics

| Metric | Definition | Range | Better |
|---|---|---|---|
| **Raw seat count** | Number of districts where the candidate given the highest probability actually won, out of all districts (88 in Victoria) | 0-88 | Higher |
| **Brier score** | For each seat, add up (p − o)² over the candidates, where p is the probability given to a candidate and o is 1 if they won and 0 if not. Average across seats. | 0-2 | Lower (0 is perfect) |
| **Log loss** | The average of −ln(p) for the candidate who actually won | 0-∞ | Lower (0 is perfect) |

Details:

- **Missing outcomes.** A candidate the model gave no row counts as p = 0, so a winner the model
  ignored scores (0 − 1)² = 1 in the Brier sum.
- **Log loss floor.** A winner with p = 0 would make log loss infinite, so p is floored at **0.001**
  (a cost of 6.9 for that seat).
- **What the metrics reward.** The raw seat count only looks at the favourite. Brier and log loss also
  reward calibrated confidence: a 55% call that loses costs little, a 99% call that loses costs a lot
  (log loss punishes it much harder than Brier).
- **Matching.** Outcomes are matched by **party group** (`ALP`, `LP`, `NP`, `GRN`, `ON`, `IND*`, …)
  or by **candidate name**. Party matching suits models that forecast parties (model1); independents
  are a single `IND*` group, so a federal independent and a different state independent count as the
  same outcome.

## Running

```bash
.venv/bin/python scripts/score_model.py <run>/seat_probabilities.csv --year 2022 [--key party|candidate]
```

Prints the three metrics and writes `scores.json` next to the forecast. Code:
`src/vic_election/benchmark.py`; declared winners come from `data/{year}/distributions/official_{year}.json`.

## Benchmark elections

Runs are named `STATEyyyy (federal year)`: the state election, and the federal election whose
polling-place results feed the model. The scored set is the **latest state election in each
single-member state**: Tasmania uses multi-member Hare-Clark and is excluded. Victorian winners come
from the VEC; the others from `data/benchmarks/winners/` (`scripts/fetch_state_winners.py`, totals
checked against the official results). The polling place → district assignment behind every run is
checked in [`booth_assignment_checks.md`](booth_assignment_checks.md) (`scripts/check_booth_assignment.py`).

## Results

The canonical table is [`forecast_backtests.csv`](forecast_backtests.csv) — every model x the five
elections plus the unscored VIC 2026 rows, regenerated by `scripts/build_forecast_backtests.py`.
Each model forecasts using only information available before the election: model1 replays the most
recent federal election's booth votes; model3 rescales those votes to the final polls (chosen
variant `L0-C0-R2`); model2's `(F)` runs start from the previous state election's primaries, flows,
final polls and candidate list. Regional deviations use the eight Legislative Council regions in
Victoria and ABS ASGS Edition 3 SA4 groups outside it (`data/benchmarks/regions/`); adopting the SA4
groups moved model2's mean log loss from 0.412 to 0.402 across the four non-Victorian forecast
backtests with seats right unchanged (`region_experiment.csv`). The SA and WA `(F)` baselines remap located
polling-place votes onto the new boundaries; the NSW baseline instead uses the official
elector-transfer table from the 2021 redistribution report (electors moved between each 2019 and
2023 district), which conserves every old district's electors exactly. The `model2 fed` rows are the
same model with a federal baseline: the preceding federal election's votes in each state district
(located booth votes plus each division's declaration and unlocated votes raked to each district
part's own party mix, `scripts/build_fed_primaries.py`) and flows fitted on the AEC's round-by-round federal
distributions; for NSW the exhaustion rates still come from the state counts (federal voting is
fully preferential). Replays given the actual primaries were removed on 16 Nov 2026
(they did not measure forecasting).
